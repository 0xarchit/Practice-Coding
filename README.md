# Practice Coding

Personal repository for coding practice during my B.Tech 3rd year: DSA practice, competitive programming problems, and class materials.

## What's inside

```
Practice Coding 1/          Current practice folder
  Codechef/                CodeChef practice problems
  Codeforces/              Codeforces problems
  Hackerrank/              HackerRank practice problems
  Leetcode/                LeetCode practice problems
  Docs/                    Class resources
  hello.java               First program: prints "hello" without a semicolon
Practice Coding 2/          Empty: reserved for next semester
Practice Coding.iml        IntelliJ IDEA module file
```

## Conventions

- Written in **Java 8** (per `Docs/Java8.pdf`), solutions run from the command line or IntelliJ IDEA.
- Each problem is a standalone `.java` file, usually with a `main` + a `solve(Scanner)` method reading from standard input.
- Files are named by problem slug (e.g. `NextRound.java`, `SoldierAndBananas.java`).

## How to run

### IntelliJ IDEA (simplest)

1. Open this folder as a project (File > Open).
2. Navigate to any solution, e.g. `Practice Coding 1/Codeforces/NextRound.java`.
3. Click the green arrow next to `main` (or right-click > Run `NextRound.main()`).
4. Enter the input in the Run console when prompted, then press Enter.

### Command line

```bash
# from the folder containing the .java file
javac NextRound.java
java NextRound
```
